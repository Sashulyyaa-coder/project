# Комплимент-бот

Telegram-бот, который делает людям приятно: отправляет тёплые, искренние и поддерживающие комплименты.

## Цель

Проект помогает людям получать небольшую эмоциональную поддержку в течение дня и упрощает процесс придумывания добрых слов для себя, близких или участников чата.

## Ключевые функции

- Ответ на сообщение пользователя подходящим комплиментом.
- Подбор комплимента по ключевым словам и контексту.
- Выбор стиля: тёплый, весёлый, «как от бабушки».
- Команды `/start`, `/help`, `/compliment`.
- Возможность расширения под персональные сообщения, ежедневные напоминания и групповые чаты.

## Технологии

- Python
- aiogram
- Telegram Bot API
- SQLite / JSON для хранения шаблонов и данных

## Как запустить

1. Клонировать репозиторий.
2. Установить зависимости.
3. Создать `.env` с токеном Telegram-бота.
4. Запустить бота.
